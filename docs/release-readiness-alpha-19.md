# Agent Driver alpha.19 출시 검증

`0.1.0-alpha.19`는 최신 범용 런타임을 공개 사본으로 분리해 검증하는 개발 alpha다. 이 문서의 수치는 원본 소스, 공개 사본, 실제 사용자 환경을 섞지 않는다. 아직 검증을 마치지 않은 항목은 성공으로 적지 않는다.

## 이번 공개 범위

- 기존 8개 웹·데이터 Pack family에 로컬 Git 프로젝트용 실험적 `coding.orchestrate`를 추가한다. 등록된 프로젝트의 정확한 CLI 세션과 단계 영수증, Git 상태 지문, 로컬 인계 문서를 사용한다. 외부 Codex/Claude 대화 세션의 자동 수입이나 GitHub 푸시는 포함하지 않는다.
- Work 접수·경량 업무 화면, 시작 전/미시작 단계의 일시정지·지침 수정, 검증된 결정 사례의 제한적 재사용을 포함한다. Run 성공만으로 Work 완료를 선언하지 않는다.
- 구독 클라이언트 사이의 도구 없는 구조화 판단 인계와 클라이언트별 저장 모델을 사용한다. 구독에서 유료 API로 자동 전환하지 않으며, 불확실한 쓰기를 다른 클라이언트가 자동 재실행하지 않는다.
- Jev는 선택 사항이다. 없는 경우 연결한 LLM을 사용한다. Jev 확률은 실행 권한이나 성공 증거가 아니다.

## 검증 결과

2026-09-24 최신 원본의 빠른 전체 회귀는 **498/498 PASS**이고, 테스트 입력 변경은 0건이다. 여기에는 선택한 Node로 설치하기, 설치 후 Chromium 실제 실행 확인, API/구독 화면 전환, 로컬 Git 코딩 인계와 Work/Swarm 회귀가 포함된다. 원본 작업 공간의 근거는 `tests/evidence/runtime-tests-2026-09-24T05-36-43-387Z.json`이며 원시 실행 증거는 공개하지 않는다.

개인 업무와 비공개 증거를 제외해 새로 만든 공개 후보는 **308개 파일**(이미지 6개 포함)이다. Ubuntu 24.04/WSL에서 Node 22.22.0과 npm 11.11.0으로 `npm ci`, TypeScript 빌드, CLI 시작, Playwright Chromium 실행 확인, 공개 사본 전체 회귀 **473/473 PASS**를 마쳤다. 공개 회귀의 근거는 별도 후보의 `tests/evidence/runtime-tests-2026-09-24T05-59-07-750Z.json`이며 소스 전체 498건과 같은 모집단으로 취급하지 않는다. 후보 자체에서 현재 로그인된 Codex와 Claude Code 구독 CLI로 임시 로컬 Git 프로젝트의 작성→독립 검토 인계를 실행해 양 단계 성공, 검토 승인, 체크포인트 갱신을 확인했다. 이것은 임시 프로젝트의 코딩 Run 검증이지 Work 완료 판정이나 실제 사용자 프로젝트 변경이 아니다.

공개 파일 해시·비밀정보·개인 도메인·문서 링크·라이선스/NOTICE 감사를 통과했고, 전체 및 운영 의존성의 `npm audit` 결과는 각각 취약점 0건이었다. 최초 공개 투영은 TypeScript 파일의 치환 오류로 빌드가 실패했다. 그 후보와 실패 manifest를 보존하고 투영 규칙을 수정한 **두 번째 후보**에서 위 검증을 통과했다. 실패를 최초부터 성공한 것으로 재분류하지 않는다. 이전 `alpha.18` 검증은 [별도 기록](release-readiness-alpha-18.md)에 남긴다.

## 현재 제공하지 않는 보장

임의 사이트 자동 적응, 9개 family 전부의 실계정 쓰기 검증, Work 완료 조건의 독립 판정, 기존 외부 CLI 대화 수입, 모든 실패에서 무감독 재개, 꺼진 PC에서도 계속되는 작업, native Windows/macOS 전체 앱 제어는 보장하지 않는다. Ubuntu/WSL의 지원 범위와 인증·승인 조건은 [README](../README.md)에 명시한다.
