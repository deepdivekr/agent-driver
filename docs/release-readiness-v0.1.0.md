# Agent Driver v0.1.0 출시 게이트

검증 시점: **v0.1.0 로컬 출시 게이트 통과.** 이 문서는 게시 전에 수행한 성공·실패·미실행 근거를 분리해 기록한다. 원격 `main`·태그·CI 상태는 [GitHub Actions](https://github.com/deepdivekr/agent-driver/actions/workflows/runtime.yml)에서 해당 커밋으로 별도 확인한다. `alpha.19` 공개 기록은 [별도 문서](release-readiness-alpha-19.md)에 있다.

## 지원 경계

- 설치·로컬 MCP: Ubuntu 24.04 x86_64 및 Windows 11 WSL2의 Ubuntu 24.04를 대상으로 검증한다. 같은 WSL 안의 CLI와 Windows 호스트의 MCP 클라이언트 연결은 별도 경로다.
- 기본 브라우저 작업: 설치된 Playwright Chromium의 전용 프로필을 사용한다. Ubuntu VM은 선택 사항이며 KVM/QEMU가 있는 호스트에 한정한다.
- 코딩 업무: 등록한 로컬 Git 프로젝트와 로그인된 Codex/Claude CLI를 사용한다. 기존 Codex 대화 세션의 선택·1턴 재개는 별도 대화형 경로이고, 사용자 지시 전 자동 다음 턴은 없다.
- Jev와 유료 API 연결은 선택 사항이다. 인증·결제·실사이트 제출은 이 릴리스 검증에서 자동으로 수행하지 않는다.
- native Windows·macOS 설치, 모든 사이트의 자동 적응, 악성 사이트 보안 격리, 전원 종료 중 실행은 지원한다고 주장하지 않는다.

GitHub `main`·`v0.1.0` 태그의 동일 SHA와 원격 CI 성공은 게시 후 확인해야 하는 별도 게이트다. 게시 전 이 문서에서 성공했다고 예고하지 않는다. 임시 설치의 production `doctor`가 `health=degraded`, `verified_for_environment=false`인 것은 실제 사이트·계정 권한을 위임하지 않았기 때문이며, 이를 사용자 환경 검증 성공으로 바꾸지 않는다. 테스트용 저장의 성공 역시 실사이트 제출 성공을 의미하지 않는다.

위 상태는 각 검증을 마친 뒤 결과와 근거 경로로 갱신한다. 검증하지 못한 플랫폼이나 pack의 실서비스 쓰기는 일반 지원으로 확대하지 않는다.

실패 기록은 성공 기록으로 바꾸거나 삭제하지 않았다. 시간 제한 변경은 별도 프로세스 준비·직렬 실행의 관찰 예산에만 적용했고, 작업 효과·중복·권한·자원 경계 판정은 유지했다.

공개판에는 평가 전용 `Stagehand`·`jev-browser`와 그 개발 의존성을 투영하지 않는다. 원본 개발 환경의 전체 `npm audit`는 2026-09-24 현재 7건(높음 1, 중간 4, 낮음 2)을 보고했고 운영 의존성 `npm audit --omit=dev`는 0건이었다. 공개 후보의 잠금 파일과 전체/운영 의존성은 별도로 다시 감사한다.
