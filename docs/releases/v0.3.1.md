# Agent Office v0.3.1

- Repository and package name: agent-office.
- Primary commands: `agent-office mcp` and `agent-office connect`.
- New installations: `~/.local/share/agent-office`; toolchain: `~/.local/share/agent-office-runtime`.
- New settings and Work data: `~/.agent-office`. Existing `~/.agent-driver` data is reused without moving it.
- Concise English/Korean READMEs include three current UI screenshots with sample data.

Finish active work and stop connected MCP clients, the shared service and Control Center before updating.
Run the new installer, then register/reconnect MCP from the new Control Center.
Old installations and launchers are not deleted or overwritten. A legacy command alias is installed only if absent.

If both default data directories contain a connection, select the intended one explicitly with
`AGENT_OFFICE_CONNECTION_ROOT` or `agent-office connect --state-root /absolute/path`.
Use the same explicit root for MCP. Do not mix two roots for the same Work.

Ubuntu 24.04 x86_64 / Windows 11 WSL2 remain the supported runtime.
Native Windows desktop control is experimental; macOS and guest browser transports remain unverified.
Internal protocol/configuration IDs and historical release assets keep their compatibility names.
