# Agent Office v0.3.0

Local MCP runtime for browser, CLI and file work on Ubuntu 24.04 x86_64
and Windows 11 through WSL2 Ubuntu 24.04.

## Highlights

- One shared MCP server replaces a full runtime per conversation.
- Browser setup checks Playwright, Aside and Neo before optional registration.
- Read-only browser routing preserves checkpoints and authorized environments.
- Existing private workflows can connect through a reviewed compatibility bridge.
- Stronger subscription billing checks, client handoff and context handling.
- Explicit shared-server stop and package-version fencing during updates.
- UIA-first Windows desktop work gains bounded visual observation and recovery
  as an experimental, separately configured capability.
- Shorter English and Korean setup guides.

## Before updating

Finish active work and disconnect clients. Stop the shared service and Control
Center before updating. Settings and Work data are preserved by the managed
installer. Reconnect afterward; live processes do not hot-reload.

Read the [update and process guide](https://github.com/deepdivekr/agent-driver/blob/v0.3.0/docs/mcp-resource-lifecycle.md).
Private workflow implementations are not included in this release.

## Scope

Jev is optional. Subscription use never silently switches to a paid API.
Aside/Neo require their own installed application and connection; their adapters
are read-only. Native Windows desktop control is experimental. macOS and Windows
VM execution are not certified. This is not an all-app desktop automation release.
