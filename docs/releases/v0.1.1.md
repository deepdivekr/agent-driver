# Agent Office v0.1.1

This patch release updates the installable Agent Driver runtime to the current Agent Office interface.

- Work-centered Control Center, English/Korean interface, live settings and action-state fixes.
- Bundled Pretendard Variable: Korean text renders without a font CDN.
- Borders and button/background states replace left-edge accent stripes.
- Explicit AI consent, saved model choices, and stale catalog-response protection.
- Subscription/auth failures never trigger an automatic paid API call. Explicitly configured API-to-subscription fallback remains available; API-key Claude sessions are not treated as subscription sessions.
- README and the one-command installer now pin the same release.

## Install or update

Run in an Ubuntu 24.04 or WSL2 Ubuntu terminal (any working directory):

```bash
bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/deepdivekr/agent-driver/v0.1.1/install.sh | bash'
```

Before an update, finish active work and stop the existing Agent Driver MCP and Control Center processes. Reconnect MCP after installation. The installer preserves settings and Work records in `~/.agent-driver`; it refuses modified or unmanaged installations. It does not hot-swap or terminate a running process.

## Verification and limits

The release workflow requires the quick regression suite, dependency audit, a fresh installation and a v0.1.0 upgrade before publishing a tag. Installation probes use actual npm, builds, Chromium, MCP and SQLite Work records; their Work-planning model is a fixture. Browser binaries may reuse the runner's preinstalled cache.

[Release readiness and evidence](https://github.com/deepdivekr/agent-driver/blob/v0.1.1/docs/release-readiness-v0.1.1.md). Ubuntu 24.04 x86_64 and Windows 11 WSL2 remain the support scope. Native Windows/macOS, real-account workflows, long soak tests and live client upgrades are not newly certified by this release.
