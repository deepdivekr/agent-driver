# 라이선스와 배포 범위

Agent Driver의 자체 소스와 문서는 [Apache License 2.0](../LICENSE)으로 공개합니다. 저작권 고지는 [NOTICE](../NOTICE), 외부 의존성 범위는 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)에 있습니다.

Apache-2.0 조건을 지키면 개인·회사 내부 사용, 수정, 재배포와 상업적 사용이 가능합니다. 이 소스를 이용한 유료 호스팅이나 cloud worker 서비스도 라이선스상 금지하지 않습니다. 같은 권한은 다른 이용자에게도 적용됩니다.

재배포 시 라이선스 사본, 관련 저작권·출처 고지와 NOTICE를 유지하고 수정한 파일에는 변경 사실을 표시해야 합니다. Apache-2.0은 상표 사용권을 부여하지 않으며, 소프트웨어는 보증 없이 제공됩니다. 상세 조건은 라이선스 원문을 따릅니다. [Apache 공식 원문](https://www.apache.org/licenses/LICENSE-2.0.html)

## 포함하지 않는 것

- 외부 의존성의 라이선스 변경
- API 이용권, 모델 가중치, Jev·LLM 구독
- 브라우저 계정, 로그인 정보, 개인 데이터와 비공개 실행 기록
- Windows 등 별도 소프트웨어의 사용권
- cloud worker 제품, 운영 지원 또는 서비스 수준 보장

코드 공개와 제품 검증은 구분합니다. Apache-2.0으로 공개해도 모든 사이트·운영체제·장애 상황에서 검증됐다는 뜻은 아닙니다. 실제 확인한 범위는 [현재 출시 검증 기록](release-readiness-v0.1.0.md)에 별도로 기록합니다.
