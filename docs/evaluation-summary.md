# 공개 평가 요약

2026-09-20. 원시 세션·모델 응답·인증·로컬 실행 환경 기록을 공개하지 않고 집계 결과와 한계를 공개한다. 공개 코드의 새로운 runtime 검사는 `npm test`로 재현 가능하다. 과거 연구의 전체 원시 자료는 현재 공개 배포에 포함되지 않는다.

|평가|실제로 확인한 것|설계에 반영한 것|
|---|---|---|
|초기 v1|실행기 5종×96회. 잘못된 실제 값/파일 검증을 보강할 필요 발견. 정책 lane은 별도|이 수치를 후속 정밀 평가와 합산해 우승 도구를 정하지 않음|
|E1 공통 제어 경로|5개 actuator 경로, 값·계정·파일 oracle, cold/warm, 실제 hidden 조건 보정|고정 순위 대신 capability/환경별 경로 검증|
|E1 hidden 조건|기본 Playwright click timeout; Stagehand/Cua/Harness/OpenCLI 해당 경로 성공. 연결 조건·표본 차이 존재|Playwright 첫 adapter는 유지하되 모든 환경 지원을 가정하지 않음|
|E2|외부 요청85회, 같은 관측 40pair 중 정규화 고유입력16개. Jev35/40, Luna구독CLI40/40. 별도30회 복구 재생은 readback으로 성공|단순 사실/검증은 코드 우선; 모델 속도와 실제 복구 효익 구분|
|G1|API 14회, 본시험6pair. Luna6/6, Jev5/6. 원문 값 있음과 후보 추출 실패를 혼동|인수 출처/존재/추출/확인 필요를 분리|
|Domain calibration|추가API9,600회, owned browser80작업 관측. 합성/실제 fixture를 분리하고 보정 후 holdout|사실 분해+코드 정책, 역할별 보정, 독립 검증, shadow-only|

Domain의 같은 balanced holdout에서:

|역할|Jev 복합 판단 정답률|사실 분해+코드 정답률|보정 후 채택|채택 오류|
|---|---:|---:|---:|---:|
|다음 행동 A|82.1%|100%|111/112|0|
|상태 S|72.9%|92.4%|118/144|1|
|다음 관측 O|97.9%|100%|96/96|0|

같은 사례에서 양쪽이 정답인 API 판단 지연은 Jev가 Luna low보다 약5.5배 짧았다. 이전 CLI 경유 10배 이상 수치와 인증/입력/실행 경로가 달라 합치지 않는다. 브라우저 전체 작업이 5.5배 빨라졌다는 결과가 아니다.

데이터를 50%→75%→100%로 늘린 보정 진단에서 분해 방식의 임계값은 유지됐다. 그러나 synthetic causal family는 독립 사용자 도메인이 아니고, 사람 검토 완료 라벨은 없다. 자연어 intake I는 추가 구간 채택률이 크게 변해 pilot 기준에 실패했다. 실제 Windows 화면/포커스 이벤트, 실제 사이트 로그인, CLI 세션, 온라인 cross-executor takeover, 전원 차단과 장기 soak는 이 결과로 인증하지 않는다.

Jev의 confidence는 권한이나 검증된 정답 확률이 아니다. 모델의 선택은 제안이고 runtime이 scope/target/account/generation/intent를 검사한다. 전체 제품을 출시할 충분성이 아니라 첫 구현 구조를 선택할 근거로 사용한다.
