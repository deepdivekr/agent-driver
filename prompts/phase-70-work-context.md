# Phase 70 — Work 계획과 압축 인계

사용자 승인 범위: 기존 제품의 로컬 구현·검증. 외부 게시·운영 배포는 포함하지 않는다.

- RQ-714: Work 정의에 버전 있는 계획을 저장하고, 가져온 단계 ID와 선행관계를 보존하며 순환·없는 의존성을 거부한다.
- RQ-715: 클라이언트·실행기 인계용 압축 계약을 실제 코딩 경로와 MCP에 연결하고 미검증 자료를 권한으로 취급하지 않는다.
- RQ-716: 프로젝트·외부 근거를 작은 색인으로 제공하고 필요한 참조만 별도 조회한다.
- RQ-717: Work별 인계 문맥 크기·중복·단계 결과·재시도·구/신 프롬프트 크기를 기록하고 미관측 토큰은 추정하지 않는다.
- RQ-718: 관련 및 기본 회귀·UI·문서·상태·인계를 검증하고 이전 실패를 지우지 않는다.
