# Phase 114 — 관제센터 한·영 문구 정리

사용자 지시: 토스 UX Writing 원칙을 기준으로 모든 제품 문구를 먼저 수정하고,
한글로 받은 수정사항도 영어 화면에 같은 의미로 적용한다.

- RQ-903: 업무 접수·상세·가져오기·온보딩·연결·설정·로그·결과 화면의 제품 문구를
  간결한 사용자 용어와 자연스러운 문장으로 통일하고 영어 의미를 맞춘다.
- RQ-904: 비용·승인·완료·전달의 실제 의미를 유지하고 사용자 지침·AI 답변·파일·
  기술 기록은 원문 그대로 보존한다. 반복 번역으로 화면이 멈추지 않게 한다.
- RQ-905: 관련 화면과 전체 quick 회귀·ledger·공개 경계를 확인하고 실제 열린
  관제센터를 한·영 데스크톱·모바일에서 확인한다. 개인 업무·연결 설정은 보존한다.

실제 모델 업무 실행·메신저 전송·공개 릴리즈는 이 요청 범위가 아니다.
후속 지시(2026-10-02): 현재 변경분을 커밋하고 보호 규칙을 지키는 PR 경로로 main에 병합한다.
